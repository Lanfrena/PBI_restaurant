## Финансовый обзор ресторана февраль 2026

1. Описание проекта
- Разработка интерактивной панели управления (Dashboard) для финансового и операционного мониторинга сети ресторанов с глубоким LFL-анализом («день недели к дню недели») и контролем план-фактных показателей за февраль 2026 года.

2. Цель:
- Синхронизация фактических продаж текущего периода (2026 г.), исторических данных (2025 г.) и бюджетных планов в разрезе каналов продаж (Ресторан, Доставка, Банкеты) и производственных подразделений для оперативного управления P&L и выявления точек падения маржинальности.
  
4. Стек технологий
   - Power BI Desktop
   - Power Query (M): Очистка и фильтрация транзакционных данных (исключение модификаторов и допов с нулевой стоимостью), консолидация разрозненных таблиц фактов (2025 и 2026 гг.), нормализация справочников типов заказов и подразделений (Кухня, Бар, Вино).
   - DAX: Расчет сложных ресторанных метрик без завышения трафика, реализация кастомного Like-for-Like сдвига на 364 дня для корректного сопоставления дней недели, управление контекстом фильтрации через REMOVEFILTERS и виртуальное связывание данных через TREATAS / SELECTCOLUMNS.
     
5. Архитектура модели
- Реализована классическая схема «Звезда» (Star Schema).
- Внедрен Master-календарь, обеспечивающий сквозную фильтрацию по датам, месяцам и дням недели для всех несвязанных таблиц фактов (Факт 2025, Факт 2026, План).
- Настроена принудительная хронологическая сортировка текстовых полей (дни недели от Пн до Вс) по скрытому числовому индексу для корректной визуализации трендов.

5. Ключевые показатели и визуализация (KPIs)
- План-факт и YoY (LFL): Вывод ключевых метрик (Выручка, Выполнение плана %, YoY %) на верхнюю панель с динамическими текстовыми сносками отклонений.
- Сквозной операционный анализ: Оценка эффективности каналов по 4 метрикам одновременно (% чеков YoY, % гостей YoY, % ср. чек YoY, % ср. чек гость YoY).
- Календарные циклы: Интерактивная таблица ежедневной сверки «понедельник к понедельнику» с автоматическим скрытием лишних дней (31 число) за пределами анализируемого месяца.
- Структура меню: Визуализация долей подразделений (Кухня, Бар, Вино) для оценки стабильности структуры продаж год к году.
  
6. Аналитический аудит данных
   
В ходе проекта выявлен и устранен ряд проблем в исходных данных:
- Искусственное завышение трафика: устранено дублирование количества гостей на уровне строк с блюдами внутри одного чека (реализована логика группировки SUMX + DISTINCT + MAX).
- Разрыв календаря при LFL-анализе из-за разной длины месяцев и смещения дней недели (проблема решена через строгий расчет шага в 364 дня с жестким ограничением контекста текущего месяца).
  
 7. Вывод - Рекомендации к анализу:
•	Зал: обучить официантов доп.продажам (апселлинг, кросселлинг). Падение чека в зале на 5% лишило ресторан основного дохода.
•	Банкеты C&B: полностью перестроить маркетинг, банкетная служба. Поток банкетных заявок рухнул на 66,7%.
•	Банкеты НАШ: ввести минимальный чек от 5 500 ₽ на гостя. Текущий рост заказов обесценился из-за падения чека на 23,7%.
•	Доставка: бюджет на рекламу этого направления. Единственный растущий канал (+36% к прошлому году).
•	Слабые дни (Четверг): запустить вечерние акции (например, скидки на вино), чтобы перекрыть регулярные просадки выручки (до -23,8%).
